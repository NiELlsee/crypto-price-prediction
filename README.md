# Прогнозирование доходности криптовалюты Solana (SOL)

**Тема:** Предсказание котировок на криптовалюты  
**Объект исследования:** Solana (SOL)  
**Команда:** Елисеев Николай  
**Куратор:** Качкин Дмитрий  

## О проекте

Проект посвящён исследованию возможности прогнозирования будущей доходности криптовалюты **Solana (SOL)** на основе исторических рыночных данных и, на последующих этапах, информационного фона.

В отличие от задачи непосредственного прогнозирования цены, в проекте планируется прогнозировать **доходность на заданном временном горизонте**. Это позволит исследовать не только качество прогноза, но и практическую применимость полученных результатов для формирования торговых сигналов.

В качестве дополнительного направления планируется исследовать влияние движения Bitcoin и информационного фона на прогнозирование доходности SOL.

Итоговым этапом проекта планируется создание симуляции торговой стратегии с виртуальным балансом и проведение backtesting на исторических данных.

## Цель проекта

Исследовать методы прогнозирования будущей доходности Solana на различных временных горизонтах с использованием рыночных и информационных данных и оценить практическую применимость полученных прогнозов в симуляции торговой стратегии.

## Основные задачи

1. Собрать и подготовить исторические данные о Solana.
2. Провести разведочный анализ данных (EDA) и исследовать особенности движения SOL.
3. Исследовать зависимость движения SOL от динамики Bitcoin и других доступных рыночных факторов.
4. Сформировать признаки для прогнозирования будущей доходности.
5. Определить подходящие временные горизонты прогнозирования.
6. Выбрать метрики качества и разработать базовые ML-модели.
7. Исследовать более сложные ML-модели и методы feature engineering.
8. Исследовать применение нейронных сетей к задаче.
9. Исследовать возможность использования информационного фона и событийных данных в качестве дополнительных признаков.
10. Сравнить модели и проанализировать ошибки прогнозирования.
11. Разработать сервис для получения прогноза.
12. Разработать симуляцию торговой стратегии на основе прогнозов модели.
13. Провести backtesting стратегии на исторических данных.
14. Организовать логирование экспериментов и обеспечить воспроизводимость результатов.
15. Подготовить документацию, результаты исследования и итоговую презентацию.

## Дополнительное направление

После построения базовых моделей планируется исследовать влияние информационного фона на прогнозирование доходности SOL.

Предполагаемый подход:

```text
Рыночные данные SOL
        +
Данные о Bitcoin
        +
Информационные события
        ↓
Feature Engineering
        ↓
ML / DL модель
        ↓
Прогноз доходности SOL
        ↓
Торговая стратегия
        ↓
Backtesting
```

Будет проведено сравнение моделей, использующих только рыночные данные, и моделей с дополнительными источниками информации.
